User Custom Command information

Chat Commands are your customized chat commands. It can be anything. Something you want to type or a command to run.

You can seperate messages and commands by a comma to run multiple commands, but that also means that if you have a comma in your chat message, it will be ignored and treated as a seperator.

The commands are as follows:

!cchelp (This shows this text so you know how to use Custom Commands.

!savecc 1 !quote (This will save the quote command to your first saved slot. Valid numbers are 1-20. It can be run with !cc 1

!listcc (This will list your set saved commands. You can have up to 20, but it will only list those that are set.

!cc <number> (This will run the specified custom command(s) that you have saved. If it is for one that is not saved, it will be ignored.
